# 🧃 바이브 코딩 스타터 팩 (VCSP)

> 코딩을 한 번도 안 해본 사람도 **AI와 대화하면서** 자기만의 웹사이트·앱·도구를 만들 수 있게 해주는 시작 세팅입니다.

"바이브 코딩"은 코드를 직접 외워서 치는 대신, **만들고 싶은 걸 말로 설명하면 AI가 코드를 짜고, 나는 결과를 보면서 방향을 잡는 방식**이에요.
이 스타터 팩은 AI가 초보자에게 맞는 말투와 속도로 도와주게 만드는 **지침서**예요.
**어떤 AI를 쓰든, Windows든 Mac이든** 같은 방식으로 쓸 수 있어요.

## 🧭 나에게 맞는 방법 고르기

| 쓰는 AI | 이렇게 시작하세요 | 특징 |
|---|---|---|
| **ChatGPT · Claude · Gemini** (웹사이트·앱에서 채팅) | [`채팅AI용-지침.md`](채팅AI용-지침.md)의 회색 상자를 복사해 붙여넣고 `시작` | 설치 없음. AI가 준 코드를 내가 파일로 저장 |
| **Claude Code** ⭐추천 | 아래 "5분 만에 시작하기" | AI가 파일을 직접 만들고, 저장·되돌리기·안전장치까지 자동 |
| **Cursor · Codex · Gemini CLI · Copilot** | 이 폴더를 열고 "시작하고 싶어"라고 말하기 | `AGENTS.md` 지침을 자동으로 읽어요 ([자세히](docs/07-다른-도구에서-쓰기.md)) |

> 처음이라 아무것도 설치하기 싫다면 **채팅 AI로 맛보기 → 재밌으면 Claude Code** 순서를 추천해요.

## ⚡ 5분 만에 시작하기 (Claude Code)

### 1. Claude Code 설치

| 환경 | 방법 |
|---|---|
| 가장 쉬움 | [Claude 데스크톱 앱](https://claude.ai/download) 설치 → **Code** 탭 사용 |
| 브라우저 | [claude.ai/code](https://claude.ai/code) 에서 이 레포 연결 |
| 터미널 (Mac/Linux) | `curl -fsSL https://claude.ai/install.sh \| bash` |
| 터미널 (Windows PowerShell) | `irm https://claude.ai/install.ps1 \| iex` |

> 터미널이 뭔지 모르겠다면 데스크톱 앱부터 쓰세요. 자세한 건 [docs/02-설치하기.md](docs/02-설치하기.md)

### 2. 이 스타터 팩 받기

GitHub에서 **Use this template** 버튼을 누르거나, 초록색 **Code → Download ZIP** 으로 받아서 압축을 푸세요.

### 3. 폴더 열고 첫 마디 하기

Claude Code에서 이 폴더를 연 뒤 이렇게 입력하세요:

```
/start
```

뭘 만들지 몰라도 괜찮아요. AI가 번호 붙은 선택지를 주면 **고르기만** 하면 돼요.

1. 시작 방법 고르기 — 만들고 싶은 게 있다 / 같이 찾아보기 / 예시에서 고르기
2. 한 문장으로 정리 — "**나**를 위한, **운동했는지 체크하는** **달력 페이지**"
3. 기능 3개 고르기 — 나머지는 "나중에"
4. 화면 미리보기 — 코드 쓰기 전에 글자 그림으로 먼저 보여줘요
5. 첫 화면 완성 → 저장

> 완성하면 어떤 모습인지 궁금하다면 [`examples/water-counter/`](examples/water-counter/)의 `index.html`을 더블클릭해 보세요.

## 🎮 명령어는 4개만 기억하세요

| 명령어 | 언제? |
|---|---|
| `/start` | 처음 시작할 때. 뭘 만들지 몰라도 OK — 고르기만 하면 계획이 세워지고 첫 화면까지 만들어요 |
| `/next` | 다음 기능 만들기. 오늘 그만했다가 다시 올 때도 이것만 입력하면 이어서 해요 |
| `/save` | 잘 될 때마다 저장! (게임 세이브 포인트) |
| `/undo` | 망했을 때 저장 지점으로 되돌리기 |

> 명령어를 몰라도 괜찮아요. "다음 거 하자", "저장해줘", "망했어"처럼 말해도 알아들어요.
> 나머지 기능은 필요할 때 AI가 먼저 권해줘요.

<details>
<summary>더 많은 명령어 보기 (6개)</summary>

| 명령어 | 언제? |
|---|---|
| `/check` | 방금 만든 게 정말 잘 되는지 점검 (빈 입력, 휴대폰 화면 등) |
| `/explain` | 코드나 에러가 무슨 뜻인지 쉽게 설명 |
| `/fix` | 뭔가 안 될 때 원인 찾고 고치기 |
| `/wrap` | 오늘은 여기까지. 저장 + 진행 상황 기록 |
| `/review` | 공개하기 전 점검 (비밀 키·깨진 부분·보안) |
| `/deploy` | 인터넷에 올려서 링크로 공유하기 |

</details>

## 🛡️ 초보자를 위한 안전장치

> 아래 자동 안전장치는 **Claude Code**에서 동작해요. 다른 AI는 같은 내용을 지침으로 따르고, 채팅 AI는 폴더 복사로 백업해요.

- 시작하자마자 원래 상태를 한 번 저장해서, **첫 작업부터** 되돌릴 수 있어요.
- 위험한 명령은 3단계로 다뤄요.
  - 🛑 **차단**: 되돌릴 수 없는 것 (컴퓨터·프로젝트 전체 삭제, 강제 푸시, 비밀 키 출력, 관리자 권한)
  - ⚠️ **확인**: 가끔 필요하지만 조심할 것 (폴더 삭제, 변경 버리기) → 이유를 보여주고 "허용할까요?" 물어봐요. 버튼만 누르면 돼요.
  - ✅ 나머지는 그대로 진행
- `.env` (비밀번호·API 키 파일)는 AI가 읽거나 만들지 못하고, GitHub에도 안 올라가요.
- 회사 파일·개인정보는 `my-project/data/`에 두면 GitHub에 안 올라가고, AI가 열기 전에 확인 창이 떠요.
- 파일 수정은 매번 묻지 않고 바로 진행해요 (허락 창이 너무 많으면 지치니까요). 대신 `/undo`로 언제든 되돌릴 수 있고, 큰 변경 전에는 AI가 **먼저 계획을 말하고 허락을 구해요**.
- 프로그램 설치나 GitHub에 올리기(push)는 항상 먼저 물어봐요.
- 진행 상황은 `my-project/PROJECT.md`에 기록돼서, 대화창을 닫았다 열어도 `/next` 한 번이면 이어서 할 수 있어요.
- 잘못돼도 `/undo` 한 번이면 되돌릴 수 있어요. 그러니 겁먹지 말고 마음껏 시도하세요.
