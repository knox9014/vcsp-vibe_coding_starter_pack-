# 🧃 바이브 코딩 스타터 팩 (VCSP)

> 코딩을 한 번도 안 해본 사람도 **AI와 대화하면서** 자기만의 웹사이트·앱·도구를 만들 수 있게 해주는 시작 세팅입니다.

"바이브 코딩"은 코드를 직접 외워서 치는 대신, **만들고 싶은 걸 말로 설명하면 AI가 코드를 짜고, 나는 결과를 보면서 방향을 잡는 방식**이에요.
이 레포를 받아서 폴더를 열기만 하면, AI가 초보자에게 맞는 말투와 속도로 도와주도록 미리 세팅돼 있어요.

---

## ⚡ 5분 만에 시작하기

### 1. Claude Code 설치

| 환경 | 방법 |
|---|---|
| 가장 쉬움 | [Claude 데스크톱 앱](https://claude.ai/download) 설치 → **Code** 탭 사용 |
| 브라우저 | [claude.ai/code](https://claude.ai/code) 에서 이 레포 연결 |
| 터미널 (Mac/Linux) | `curl -fsSL https://claude.ai/install.sh \| bash` |
| 터미널 (Windows PowerShell) | `irm https://claude.ai/install.ps1 \| iex` |

> 터미널이 뭔지 모르겠다면 데스크톱 앱부터 쓰세요. 자세한 건 [docs/02-설치하기.md](docs/02-설치하기.md)

### 2. 이 스타터 팩 받기

GitHub에서 **Use this template** 버튼을 누르거나, 초록색 **Code → Download ZIP** 으로 받아서 압축을 푸세요.

### 3. 폴더 열고 첫 마디 하기

Claude Code에서 이 폴더를 연 뒤 이렇게 입력하세요:

```
/start
```

AI가 "뭘 만들고 싶으세요?"부터 차근차근 물어보고, 아이디어를 정리해서 첫 화면까지 같이 만들어 줍니다.

---

## 🧰 들어있는 것

```
.
├── CLAUDE.md                 ← AI가 매번 읽는 "행동 지침" (초보자 모드)
├── .claude/
│   ├── settings.json         ← 위험한 명령은 막고, 안전한 건 덜 물어보게 하는 설정
│   └── skills/               ← 슬래시(/) 명령어 모음
├── docs/                     ← 사람이 읽는 가이드
├── templates/                ← 아이디어 정리용 빈 양식
├── .env.example              ← 비밀 키 넣는 법 예시
└── .gitignore                ← 올리면 안 되는 파일 목록
```

### 슬래시 명령어 (채팅창에 입력)

| 명령어 | 언제 쓰나요? |
|---|---|
| `/start` | 처음 시작할 때. 아이디어 인터뷰 → 계획 → 첫 결과물 |
| `/next` | "이제 뭐 하지?" 싶을 때. 다음 할 일 하나를 골라서 진행 |
| `/explain` | 방금 만든 코드나 에러가 무슨 뜻인지 쉽게 설명 |
| `/fix` | 뭔가 안 될 때. 원인 찾고 고치기 |
| `/save` | 지금 상태를 저장(체크포인트). 잘 될 때마다 자주! |
| `/undo` | 망했을 때. 마지막 저장 지점으로 되돌리기 |
| `/review` | 공개하기 전 점검 (보안·비밀키·깨진 부분) |

## 🛡️ 초보자를 위한 안전장치

- AI가 **파일 삭제, 강제 푸시** 같은 되돌리기 어려운 명령은 실행하지 못하게 막아뒀어요.
- `.env` (비밀번호·API 키 파일)는 AI가 읽지 못하고, GitHub에도 안 올라가요.
- AI는 큰 변경 전에 **먼저 계획을 말하고 허락을 구하도록** 지시받아요.
- 잘못돼도 `/undo` 한 번이면 되돌릴 수 있어요. 그러니 겁먹지 말고 마음껏 시도하세요.
