# /review — 공개 전 점검

아래 항목을 확인하고 결과를 **신호등**으로 보고하세요. 🟢 괜찮음 / 🟡 고치면 좋음 / 🔴 꼭 고쳐야 함

1. **비밀 정보**: 코드와 git 기록에 API 키·비밀번호·토큰이 있는지 (`git log -p`에서 키처럼 보이는 문자열 검색). `.env`가 `.gitignore`에 있는지.
2. **동작 확인**: `PROJECT.md`의 완료된 기능들이 실제로 동작하는지 가능하면 직접 실행해 보기.
3. **화면**: 휴대폰 크기에서도 깨지지 않는지 (viewport 메타 태그, 고정 너비 등).
4. **사용자 입력**: 입력값을 그대로 HTML에 넣는 곳(`innerHTML`)이 있으면 🟡로 알리기.
5. **기본 정보**: README나 페이지 제목이 프로젝트에 맞게 바뀌었는지.

🔴가 있으면 그것부터 고칠지 물어보세요. 전부 🟢/🟡면 축하하고, 배포 방법(GitHub Pages, Vercel 등)을 원하면 안내하겠다고 제안하세요.
