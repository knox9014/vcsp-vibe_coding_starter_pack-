# /fix — 문제 고치기

## 1. 증상 파악 (모르면 물어보기, 질문은 최대 2개)

- 무엇을 했을 때, 무엇을 기대했는데, 실제로는 어떻게 됐나요?
- 에러 메시지가 있으면 그대로 붙여넣어 달라고 하세요. 웹페이지라면 콘솔(에러가 표시되는 곳)의 빨간 글씨를 복사하는 법을 알려주세요:
  - Windows: `F12` 또는 `Ctrl + Shift + J` → Console 탭
  - Mac: `Cmd + Option + J` (크롬) / 사파리는 먼저 설정 → 고급 → "웹 개발자용 기능 보기" 켜기
- 스크린샷을 붙여넣어도 된다고 알려주세요.

## 2. 원인 찾기

- 관련 파일을 읽고, 최근 변경(`git diff`, `git log -5`)을 확인하세요. 최근에 바꾼 곳이 원인일 가능성이 높습니다.
- 가능하면 직접 실행해서 재현하세요. 웹페이지는 브라우저 도구(예: 이미 설치된 Playwright)가 있으면 직접 열어 콘솔 에러를 확인하세요. 없으면 사용자에게 콘솔 내용을 받으세요 — 확인만을 위해 새 도구를 설치하지 마세요.

## 3. 설명 후 고치기

- 원인을 **한두 문장**으로 쉽게 설명하세요.
- 가장 작은 수정으로 고치세요. 관련 없는 코드는 건드리지 마세요.
- 고친 후 사용자가 확인하는 방법을 알려주세요.

## 4. 두 번 시도해도 안 되면

- 솔직하게 말하고, 선택지를 주세요: ① 다른 방법으로 접근 ② `/undo`로 마지막 저장 지점으로 돌아가기 ③ 기능을 더 단순하게 바꾸기
- 같은 방법을 계속 반복하지 마세요.
