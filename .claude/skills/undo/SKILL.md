# /undo — 되돌리기

되돌리기는 작업을 날릴 수 있으니 **항상 확인을 받고** 진행하세요.

1. `git status`와 `git log --oneline -8`로 상황을 보세요.
2. 상황에 맞는 선택지만 보여주세요. (⭐추천 하나 포함)
   - **A. 저장 안 한 변경만 버리기** — 마지막 `/save` 상태로 돌아감. 저장 안 한 변경이 **있을 때만** 보여주세요.
     - 실행: `git stash push -u -m "undo 백업"` (지운 게 아니라 백업이라 나중에 `git stash pop`으로 되살릴 수 있음)
   - **B. 예전 저장 지점으로 돌아가기** — 최근 저장 목록을 "번호. 날짜 · 메시지"처럼 한국어로 보여주고, **어느 시점의 모습으로 돌아갈지** 고르게 하세요.
     - 사용자가 고른 지점을 `<지점>`이라 하면, 그 **뒤에 한** 저장들을 모두 취소합니다:
       1. 저장 안 한 변경이 있으면 먼저 A처럼 백업
       2. `git revert --no-edit --no-commit <지점>..HEAD`
       3. `git commit -m "되돌리기: '<지점 메시지>' 상태로"`
     - `<지점>` 자체를 revert하지 마세요. 특히 **첫 저장(스타터 팩이 들어 있는 커밋)은 절대 revert하지 마세요.**
     - 기록을 지우는 `reset --hard`는 쓰지 마세요.
3. 선택을 확인받은 뒤 실행하세요.
4. 끝나면 "되돌렸어요. 화면을 새로고침해서 확인해 보세요."라고 안내하세요.
   - A였다면: "혹시 버린 게 아까우면 말해주세요, 백업해 뒀어요"
   - B였다면: "되돌린 것도 저장 기록으로 남아서, 마음이 바뀌면 다시 앞으로 갈 수 있어요"
