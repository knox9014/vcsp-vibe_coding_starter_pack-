# /undo — 되돌리기

되돌리기는 작업을 날릴 수 있으니 **항상 확인을 받고** 진행하세요.

1. `git status`와 `git log --oneline -5`로 상황을 보세요.
2. 사용자에게 선택지를 보여주세요:
   - **A. 저장 안 한 변경만 버리기** — 마지막 `/save` 상태로 돌아감
     (`git stash push -u -m "undo 백업"` 으로 백업해 두고 되돌리기 → 나중에 되살릴 수 있음)
   - **B. 특정 저장 지점으로 돌아가기** — 최근 커밋 목록을 한국어로 보여주고 고르게 하기
     (`git revert`로 되돌리는 새 커밋을 만드세요. 기록을 지우는 `reset --hard`는 쓰지 마세요)
3. 선택을 확인받은 뒤 실행하세요.
4. 끝나면 "되돌렸어요. 화면을 새로고침해서 확인해 보세요."라고 안내하고, A를 골랐다면 "혹시 버린 게 아까우면 말해주세요, 백업해 뒀어요"라고 덧붙이세요.
