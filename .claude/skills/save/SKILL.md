# /save — 체크포인트 저장

1. git 저장소가 아니면 `git init`을 실행하고 "이 폴더의 변경 기록을 시작했어요"라고 알려주세요.
2. `git status`로 바뀐 파일을 확인하세요. 바뀐 게 없으면 "이미 다 저장돼 있어요!"라고 하고 끝.
3. **비밀 정보 점검**: `.env`, 키·토큰·비밀번호처럼 보이는 값이 커밋될 파일에 있으면 멈추고 알려주세요. `.env`가 `.gitignore`에 있는지도 확인하세요.
4. `git add -A` 후, 무엇이 바뀌었는지 **한국어 한 줄**로 커밋 메시지를 쓰세요. 예: `할 일 추가 버튼 만들기`
5. 결과를 이렇게 알려주세요:
   - "💾 저장했어요: ○○○"
   - "문제가 생기면 `/undo`로 언제든 여기로 돌아올 수 있어요."

GitHub에 올리기(push)는 사용자가 따로 요청할 때만 하세요.
