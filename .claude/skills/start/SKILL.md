# /start — 첫 프로젝트 시작하기

사용자는 코딩 초보입니다. 아래 순서를 지키되, 대화는 가볍고 따뜻하게 진행하세요.

## 1단계: 인사 & 이미 진행 중인지 확인

- `PROJECT.md`가 이미 있으면 읽고, "지난번에 ○○를 만들고 있었네요. 이어서 할까요, 새로 시작할까요?"라고 물어보세요.
- 없으면 한 줄로 환영 인사 후 2단계로.

## 2단계: 아이디어 인터뷰 (한 번에 질문 1~2개씩)

다음을 차례로 물어보세요. 사용자가 막막해하면 `docs/06-첫-프로젝트-아이디어.md`에서 예시 3개를 골라 보여주세요.

1. 무엇을 만들고 싶나요? (한 문장이면 충분)
2. 누가 쓰나요? (나 혼자 / 친구들 / 아무나)
3. 가장 중요한 기능 **딱 하나**는?
4. 참고하고 싶은 느낌이나 사이트가 있나요? (없어도 OK)

## 3단계: PROJECT.md 만들기

- `templates/PROJECT_BRIEF.md`를 복사해 루트에 `PROJECT.md`로 만들고, 답변으로 채우세요.
- 할 일 목록은 **3~5개의 아주 작은 단계**로 쪼개세요. 첫 단계는 반드시 "화면에 뭔가 보이기"여야 합니다.
- 기술 선택은 CLAUDE.md의 "기술 선택 기본값"을 따르세요.
- 완성된 계획을 5줄 이내로 요약해 보여주고 "이대로 시작할까요?"라고 확인받으세요.

## 4단계: 첫 결과물

- 할 일 1번만 만드세요. (보통 `index.html` 하나)
- 확인 방법을 단계별로 알려주세요. 예: "왼쪽 파일 목록에서 index.html을 찾아 더블클릭 → 브라우저에서 열려요"
- 보이는 게 마음에 드는지 물어보세요.

## 5단계: 첫 저장

- 아직 git 저장소가 아니면 `git init`을 하세요.
- 커밋이 뭔지 한 줄로 설명하고("게임 세이브 포인트 같은 거예요"), 동의하면 첫 커밋을 만드세요.
- 마지막으로 "다음엔 `/next`라고 입력하면 이어서 진행해요"라고 안내하세요.
