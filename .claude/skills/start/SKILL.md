# /start — 무엇을 만들지 정하고 첫 화면 만들기

사용자는 코딩 초보이고, **무엇을 만들지 정하는 것 자체를 어려워합니다.**
목표는 사용자가 **직접 글을 길게 쓰지 않고, 고르기만 해도** 계획이 완성되는 것입니다.

## 진행 원칙 (모든 단계 공통)

- 질문할 때는 항상 **번호 붙은 선택지 2~4개 + ⭐추천 하나**를 주세요. "1번", "추천대로"만 말해도 넘어가게.
  - Claude Code에서 선택지 질문 도구(AskUserQuestion)를 쓸 수 있으면 그걸 쓰세요. 클릭으로 고를 수 있어 입문자에게 훨씬 쉽습니다.
- 사용자가 "알아서 해줘", "몰라요", "아무거나"라고 하면 ⭐추천으로 정하고 바로 다음 단계로 가세요.
- 사용자가 말한 아이디어가 크면(예: "배달 앱") 깎아내리지 말고 "좋아요! 그중 제일 핵심인 부분부터 만들어 봐요"라고 작은 첫 버전을 제안하세요.
- 메시지는 짧게. 아래 단계에서 **"(질문 1번)"이라고 표시된 곳에서만** 사용자에게 묻고, 그 외에는 묻지 말고 진행하세요.

### 질문 횟수 (첫 화면까지 최대 5번)

| 시작 방법 | 질문 순서 | 횟수 |
|---|---|---|
| 1. 만들고 싶은 게 있음 | 시작 방법 → 문장+기능 → 계획 카드 | 3번 |
| 3. 예시에서 고르기 | 시작 방법 → 예시 → 문장+기능 → 계획 카드 | 4번 |
| 2. 같이 찾기 | 시작 방법 → 두 질문 한 번에 → 아이디어 → 문장+기능 → 계획 카드 | 5번 |

## 1단계: 이어서 할지 확인

- `my-project/PROJECT.md`가 이미 있으면 읽고, "지난번에 ○○를 만들고 있었네요. 이어서 할까요, 새로 시작할까요?"라고 물어보세요. 이어서 하면 `/next` 절차로 넘어가세요.
- 없으면 한 줄로 환영 인사 후 2단계로.

## 2단계: 시작 방법 고르기 (질문 1번)

> 무엇을 만들지 정해볼게요. 어디에 가까우세요?
> 1. 만들고 싶은 게 있어요 → 한 줄로 말해주세요
> 2. 아직 잘 모르겠어요 → 질문 두 개로 같이 찾아봐요
> 3. 일단 뭐라도 빨리 만들어 보고 싶어요 → 예시 중에 골라요 ⭐처음이라면 추천

**1번**: 사용자의 한 줄을 받아 3단계로. (선택지 도구를 쓴다면 "Other 칸에 한 줄로 적어주세요"라고 안내)

**2번** (질문 1번): 아래 두 질문을 **한 번에** 물어보세요. 선택지 도구는 질문 여러 개를 한 번에 보낼 수 있습니다.
- "요즘 귀찮거나, 자꾸 까먹거나, 반복하는 일은?" (예: 공부 시간 재기 / 물 마시기 / 돈 쓴 거 정리 / 약속 날짜)
- "좋아하는 것이나 취미는?" (예: 운동 / 게임 / 음식 / 여행 / 반려동물 / 음악)

그다음 (질문 1번) 두 답을 섞은 **맞춤 아이디어 3개**를 고르게 하세요. 각각 한 줄 설명 + 난이도(⭐~⭐⭐⭐), 가장 쉬운 하나에 ⭐추천.
> 예) 운동 + 까먹음 → 1. 오늘 운동 체크 달력 (⭐) ⭐추천 / 2. 운동 루틴 랜덤 뽑기 (⭐) / 3. 한 달 운동 기록 그래프 (⭐⭐)

**3번** (질문 1번): `docs/06-첫-프로젝트-아이디어.md`의 "⭐ 30분이면 첫 결과가 보이는 것" 4개를 번호로 보여주고 고르게 하세요.

## 3단계: 한 문장 + 기능 고르기 (질문 1번)

**한 메시지에** 아래 두 가지를 보여주고 한 번만 물어보세요.

1. AI가 채운 **한 문장 초안** ("누가 쓰나요?"는 따로 묻지 말고 기본값 "나")
   > 📌 **나**를 위한, **오늘 운동했는지 체크하는** **달력 페이지**
2. 기능 후보 **5~6개** 체크리스트. **딱 3개에 ⭐이번에**, 나머지는 **⏭️ 나중에**
   > 1. ⭐ 오늘 날짜에 "했어요" 버튼
   > 2. ⭐ 이번 달 달력에 체크 표시
   > 3. ⭐ 새로고침해도 기록 유지
   > 4. ⏭️ 연속 며칠째인지 보여주기
   > 5. ⏭️ 친구랑 같이 보기
   > 6. ⏭️ 알림 보내기

질문: "이대로 할까요?" — 선택지 예: ⭐추천대로 / 더 간단하게(⭐ 중 2개만) / 다른 조합(번호로 말하기) / 문장을 고치고 싶어요

- 로그인, 결제, 여러 명이 동시에 쓰기, 알림은 기본적으로 ⏭️ 나중에 두고, 왜 나중에인지 한 줄로 설명하세요 ("처음엔 어렵고 안전하게 만들기 까다로워요").
- 고른 기능이 3개를 넘으면 "처음 버전은 3개만 해보고, 나머지는 완성 후에 추가해요"라고 제안하세요.

## 4단계: 계획 카드 + 화면 미리보기 + 분위기 (질문 1번)

**한 메시지에** 계획 카드와 **글자 그림(ASCII) 화면 스케치**를 보여주고, 마지막 질문으로 **분위기를 고르게** 하세요. 분위기를 고르면 "이 계획대로 시작"에 동의한 것으로 봅니다.

```
📌 만들 것: 나를 위한, 오늘 운동했는지 체크하는 달력 페이지
✅ 이번에 만들 것: ① 했어요 버튼 ② 달력 체크 ③ 기록 유지
⏭️ 나중에: 연속 기록, 친구랑 보기, 알림
🧱 순서: 1. 화면에 제목·달력·버튼 보이기  2. 버튼 누르면 오늘 칸에 ✅  3. 새로고침해도 ✅ 유지

┌──────────────────────────┐
│   🏃 오늘 운동 체크        │
│   11월                   │
│   월 화 수 목 금 토 일      │
│   ✅ ✅ ·  ✅ ·  ·  ·      │
│   [ 오늘 운동했어요! ]      │
└──────────────────────────┘
```

> 이렇게 만들어 볼게요! 분위기만 골라주세요.
> 1. 깔끔한 흰색 ⭐추천  2. 귀여운 파스텔  3. 어두운 다크 모드  4. 계획을 바꾸고 싶어요

"계획을 바꾸고 싶어요"를 고르면 무엇을 바꿀지 듣고 카드를 고쳐서 다시 보여주세요. (이건 횟수에 세지 않습니다)

## 5단계: 계획 파일 저장

묻지 말고 진행하세요.
- `templates/PROJECT_BRIEF.md`를 복사해 `my-project/PROJECT.md`로 만들고 계획 카드, 분위기, 화면 스케치로 채우세요. (`my-project/README.md` 안내문은 지워도 됩니다)
- 할 일마다 `→ 확인: (어떻게 되면 성공인지)`를 붙이세요. 첫 할 일은 반드시 "화면에 뭔가 보이기"입니다.
- 기술 선택은 AGENTS.md의 "기술 선택 기본값"을 따르고, 사용자에게 따로 묻지 마세요.
- "앞으로 만드는 건 전부 `my-project` 폴더 안에 생겨요"라고 한 줄로 알려주세요.

## 6단계: 첫 결과물

- 할 일 1번만 만드세요. (보통 `my-project/index.html` 하나) 스케치와 고른 분위기를 따르세요.
- 확인 방법을 단계별로 알려주세요. 예: "왼쪽 파일 목록에서 `my-project` 폴더 → `index.html` 더블클릭 → 브라우저에서 열려요"
- "스케치랑 비슷하게 나왔나요? 바꾸고 싶은 게 있으면 말해주세요"라고 물어보세요.

## 7단계: 첫 저장

- 아직 git 저장소가 아니면 `git init`을 하세요.
- 커밋이 뭔지 한 줄로 설명하고("게임 세이브 포인트 같은 거예요"), 동의하면 첫 커밋을 만드세요.
- 마지막으로 이렇게 안내하세요:
  - "다음 기능은 `/next`, 오늘 그만할 땐 `/wrap` 하면 돼요."
  - 완성 예시가 궁금하면 `examples/water-counter/`를 열어보라고 알려주세요.
