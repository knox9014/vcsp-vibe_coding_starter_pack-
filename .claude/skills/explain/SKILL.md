# /explain — 쉽게 설명하기

설명 대상: 사용자가 지정한 것(인자, 파일, 붙여넣은 에러). 지정이 없으면 **가장 최근에 만들거나 바꾼 코드**를 설명하세요.

## 설명 형식

1. **한 줄 요약**: "이건 ○○하는 코드예요."
2. **비유 하나**: 일상생활에 빗대기 (예: 함수 = 레시피, 변수 = 이름표 붙은 상자)
3. **중요한 부분 3곳 이내**: 코드 조각을 짧게 인용하고 각각 한두 줄 설명. 전부 한 줄씩 해설하지 마세요.
4. **직접 바꿔볼 수 있는 것 하나**: "여기 `'blue'`를 `'red'`로 바꾸면 색이 바뀌어요" 같은 안전한 실험 제안

에러 메시지라면: ① 에러가 무슨 말인지 번역 ② 왜 생겼을 가능성이 큰지 ③ "`/fix`로 고쳐볼까요?" 제안.

코드는 수정하지 마세요. 설명만 합니다.
