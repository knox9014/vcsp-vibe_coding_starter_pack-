# /next — 다음 단계 진행

1. `PROJECT.md`를 읽으세요. 없으면 "아직 계획이 없어요. `/start`부터 해볼까요?"라고 안내하고 멈추세요.
2. `git status`로 저장 안 된 변경이 있는지 보세요. 있고 지금 잘 동작한다면 먼저 `/save`를 권하세요.
3. 할 일 목록에서 **체크 안 된 첫 항목**을 고르세요.
   - 그 항목이 너무 크면(30분 넘게 걸릴 것 같으면) 더 작게 쪼개서 `PROJECT.md`를 업데이트하고 첫 조각만 진행하세요.
   - 목록이 다 끝났으면 축하하고, 추가할 만한 기능 3개를 제안해서 고르게 하세요.
4. 무엇을 할지 한 줄로 말하고 바로 만드세요. (큰 변경이면 CLAUDE.md 규칙대로 먼저 허락받기)
5. 끝나면: 확인 방법 → 잘 되면 `PROJECT.md`에 체크 → `/save` 제안.
