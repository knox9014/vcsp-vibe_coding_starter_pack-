# /wrap — 오늘 작업 마무리

다음 대화의 AI는 오늘 대화를 기억하지 못합니다. `my-project/PROJECT.md`가 유일한 인수인계서라고 생각하고 쓰세요.

1. **`my-project/PROJECT.md` 먼저 업데이트** (짧게, 덮어쓰기):
   - **현재 상태**: 지금 무엇이 되고 무엇이 안 되는지, 하던 일이 어디까지 왔는지. 망가진 상태라면 그 사실도.
   - **실행 방법**: 결과물이 어디 있고 어떻게 여는지/실행하는지 (예: "`my-project/index.html` 더블클릭"). 비어 있으면 꼭 채우세요.
   - **다음 할 일**: 순서대로 1~3개
   - **결정 기록**: 오늘 정한 중요한 결정과 이유 (예: "데이터는 localStorage에 저장 — 혼자 쓰니까")
   - **주의할 점**: 오늘 두 번 이상 헤맨 것
   - 완료한 할 일 체크
2. **그다음 저장**: 잘 동작하는 상태면 `/save` 절차대로 커밋하세요 (`PROJECT.md` 변경도 함께 저장됩니다). 망가진 상태면 코드는 저장하지 말고, `PROJECT.md`만 저장할지 물어보세요.
3. **사용자에게 요약** (5줄 이내):
   - 🎉 오늘 한 것
   - 📂 결과물 위치와 여는 법 (한 줄)
   - ▶️ 다음에 할 것
   - "다음엔 새 대화를 열고 `/next`라고만 하면 이어서 할 수 있어요."
