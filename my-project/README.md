# 📁 my-project — 여기에 내 프로젝트가 만들어져요

`/start`(또는 "시작하고 싶어")를 입력하면 AI가 이 폴더 안에 계획 파일(`PROJECT.md`)과 첫 결과물을 만들어 줘요.
웹페이지라면 `index.html`, 자동화라면 Python 스크립트가 생겨요.

- 이 폴더 밖의 파일들(`docs/`, `AGENTS.md` 등)은 스타터 팩 설정이라 신경 쓰지 않아도 돼요.
- 회사 파일이나 개인정보는 `data/` 폴더에 넣으세요. GitHub에 올라가지 않아요.
- 시작하면 AI가 이 안내문을 내 프로젝트 소개로 바꿔 써요.
