# 프로젝트: 물 마시기 카운터

> 한 문장 소개: 나를 위한, 오늘 마신 물 잔 수를 버튼으로 세는, 웹페이지

> 💡 이 파일은 `/start`를 하면 만들어지는 `PROJECT.md`의 **완성 예시**예요. 같은 폴더의 `index.html`을 더블클릭하면 결과물을 볼 수 있어요.

## 누가 쓰나요?

- 나 혼자 (휴대폰으로)

## 가장 중요한 기능 (최대 3개)

- 버튼을 누르면 잔 수가 올라간다
- 새로고침해도 숫자가 유지된다
- 목표(8잔)까지 몇 잔 남았는지 보인다

## 이번엔 안 할 것

- 날짜별 기록, 그래프, 로그인, 알림

## 참고 / 원하는 느낌

- 하늘색, 큼직한 숫자, 귀여운 컵 이모지

## 기술 선택

- HTML + CSS + JavaScript 파일 하나 (`index.html`), 데이터는 localStorage

## 할 일 목록

- [x] 1. 화면에 제목, 숫자 0, 버튼 보이기 → 확인: index.html을 열면 보임
- [x] 2. 버튼 누르면 숫자 +1 → 확인: 3번 누르면 3
- [x] 3. 새로고침해도 숫자 유지 → 확인: 2잔 → 새로고침 → 여전히 2
- [x] 4. 목표까지 남은 잔 수 + 달성 메시지 → 확인: 8잔이 되면 🎉 문구
- [x] 5. "처음부터" 버튼 (실수 방지 확인창) → 확인: 누르면 확인창 → 확인 시 0

## 현재 상태

- 지금: 핵심 기능 모두 동작. 휴대폰 화면에서도 확인함.
- 다음: (선택) 자정이 지나면 자동으로 0으로 초기화
- 배포 주소: (아직 없음)

## 결정 기록

- 데이터는 localStorage에 저장 — 혼자 쓰니까 서버가 필요 없음
- 리셋 버튼에 확인창 추가 — 실수로 눌러서 기록이 날아간 적 있음

## 주의할 점

- localStorage 값은 글자로 저장돼서 `Number()`로 바꿔야 숫자 계산이 됨
