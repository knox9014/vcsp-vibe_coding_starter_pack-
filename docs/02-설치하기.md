# 2. 설치하기

필요한 건 딱 두 가지예요: **Claude 계정**과 **Claude Code**.

## 0. Claude 계정 만들기

[claude.ai](https://claude.ai) 에서 가입하세요. Claude Code를 쓰려면 Pro 이상 요금제(또는 API 결제)가 필요해요.

## 방법 A. 데스크톱 앱 (추천 👍 터미널 몰라도 됨)

1. [claude.ai/download](https://claude.ai/download) 에서 내 컴퓨터(Mac/Windows)용 앱을 받아 설치
2. 앱을 열고 로그인
3. 상단의 **Code** 탭 선택
4. 이 스타터 팩 폴더를 선택해서 열기
5. 채팅창에 `/start` 입력

## 방법 B. 웹 브라우저 (설치 없음)

1. 이 레포를 내 GitHub 계정으로 복사 (**Use this template** 또는 **Fork**)
2. [claude.ai/code](https://claude.ai/code) 접속 → GitHub 연결 → 방금 만든 레포 선택
3. `/start` 입력

> 웹 버전은 클라우드에서 돌아가서, 만든 결과를 GitHub에 올려야(push) 내 컴퓨터로 가져올 수 있어요.

## 방법 C. 터미널 (조금 익숙한 분)

**Mac / Linux**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows (PowerShell)**

```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 후:

```bash
cd 스타터팩-폴더-경로
claude
```

처음 실행하면 브라우저가 열리면서 로그인하라고 해요.

## (선택) 같이 깔면 좋은 것

| 도구 | 왜? | 필수? |
|---|---|---|
| [VS Code](https://code.visualstudio.com) | 파일을 보기 편한 편집기. Claude Code 확장도 있어요 | 선택 |
| [Git](https://git-scm.com) | `/save`, `/undo` 기능에 필요. Mac은 처음 쓸 때 "개발자 도구 설치" 창이 뜨면 '설치' 클릭 | 권장 |
| [Python](https://www.python.org/downloads/) | 엑셀·파일 정리 같은 자동화를 만들 때 필요. Windows는 설치 첫 화면에서 **"Add python.exe to PATH"** 체크 | 자동화할 때 |
| [Node.js](https://nodejs.org) (LTS) | 나중에 React 등 쓸 때 필요. 처음엔 없어도 됨 | 나중에 |

> 💡 처음 `/save` 할 때 AI가 "저장 기록에 남길 이름"을 한 번 물어봐요. 별명을 적어도 돼요.
> 회사 컴퓨터라 프로그램 설치가 막혀 있다면 IT 담당자에게 Git·Python 설치를 요청하세요.

설치가 잘 됐는지 모르겠으면, Claude Code를 열고 그냥 물어보세요:
> "git이랑 node가 설치돼 있는지 확인해줘"
