# 참고자료 & 더 배우기

이 스타터 팩은 아래 공개 프로젝트들의 아이디어를 **입문자 눈높이에 맞게 한국어로 다시 정리**해서 만들었어요. 더 깊이 배우고 싶을 때 들러보세요.

## 이 스타터 팩에 반영한 것

| 프로젝트 | 가져온 아이디어 | 반영된 곳 |
|---|---|---|
| [KhazP/vibe-coding-prompt-template](https://github.com/KhazP/vibe-coding-prompt-template) | 여러 AI 도구가 같은 지침을 쓰도록 `AGENTS.md`를 공통 파일로 두기, 세션 인수인계용 기록 파일 | `AGENTS.md`, `GEMINI.md`, `.cursor/`, `PROJECT.md`의 "현재 상태" |
| [SWAGATAMBAZ/vibe-coding-playbook](https://github.com/SWAGATAMBAZ/vibe-coding-playbook) | 위험 명령 차단 훅, 세션 인수인계(handoff), 엣지 케이스 검증, 질문마다 추천 답 제시, "범위 밖" 목록 | `.claude/hooks/`, `/wrap`, `/check`, `/start` |
| [Tech-Messager/leo-vibe-starter](https://github.com/Tech-Messager/leo-vibe-starter) | "단계 → 확인 방법" 형식, 요청한 것만 바꾸기, 가장 단순한 코드 | 할 일의 `→ 확인:`, `AGENTS.md` 작업 방식 |
| [kylemoschetto/vibe-md-templates](https://github.com/kylemoschetto/vibe-md-templates) | 입문자용 권한 설정 예시, 세션 마무리 체크리스트 | `.claude/settings.json`, `/wrap` |
| [analyticalrohit/awesome-vibe-coding-guide](https://github.com/analyticalrohit/awesome-vibe-coding-guide) | 일찍 배포하기, 대화 리셋, "왜 이렇게 동작하는지" 물어보기 | `/deploy`, `docs/` |
