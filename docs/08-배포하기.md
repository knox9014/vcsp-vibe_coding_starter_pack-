# 8. 인터넷에 올리기 (배포)

내가 만든 걸 친구에게 **링크로** 보여주는 방법이에요. 가장 쉬운 건 그냥 `/deploy` 라고 입력하는 거예요. AI가 내 프로젝트에 맞는 방법을 골라 단계별로 안내해 줘요.

> 💡 **일찍, 자주 올려보세요.** 완벽해질 때까지 기다리지 말고 첫 화면이 나오면 바로 올려보는 게 좋아요. 휴대폰에서 열어보면 내 컴퓨터에선 몰랐던 문제가 보여요.

## 올리기 전에 꼭

1. `/review` — 비밀 키·개인정보가 들어가 있지 않은지 확인
2. `/save` — 저장

## 미리 알아둘 것

- **내 기록은 친구에게 안 보여요.** 데이터를 브라우저에 저장하는 페이지(기본 방식)라면, 링크를 연 사람마다 자기 기록만 보여요. 같이 보려면 데이터베이스가 필요해요.
- **폴더 안 파일은 공개돼요.** Netlify·Vercel로 올리면 `my-project/PROJECT.md`(내 메모)도 `주소/PROJECT.md`로 볼 수 있어요. 곤란한 내용은 지우고 올리세요. (GitHub Pages 설정은 자동으로 빼고 올려요)

## 방법 3가지

### A. Netlify Drop — GitHub 몰라도 됨 (HTML 프로젝트)

1. [app.netlify.com/drop](https://app.netlify.com/drop) 접속
2. `my-project` 폴더를 브라우저 창에 **끌어다 놓기**
3. 주소가 바로 나옴 (계속 유지하려면 무료 가입)

### B. GitHub Pages — 무료, 저장하면 자동 반영 (HTML 프로젝트)

0. 프로젝트가 아직 GitHub에 없다면: [GitHub Desktop](https://desktop.github.com) 설치·로그인 → File → Add local repository → 이 폴더 → **Publish repository** (Private 체크 해제)
1. AI에게 "GitHub Pages로 배포 설정해줘"라고 하기 → `my-project` 폴더를 자동으로 올려주는 설정 파일을 만들어 줘요
2. GitHub 레포 → **Settings** → 왼쪽 **Pages** → Source를 **GitHub Actions**로 선택
3. GitHub에 올리기(push) → 레포의 **Actions** 탭에서 초록색 체크 ✅ 확인
4. 1~2분 뒤 `https://내아이디.github.io/레포이름/` 으로 접속

### C. Vercel — React, Next.js 같은 프로젝트

1. [vercel.com](https://vercel.com) 에 GitHub로 가입
2. **Add New → Project** → 내 레포 선택 → **Root Directory**를 `my-project`로 바꾸기 → **Deploy**
3. 비밀 키가 필요하면 **Settings → Environment Variables** 에 넣기 (`.env` 파일은 올리지 않아요)

## 자주 묻는 것

- **돈 드나요?** 개인 프로젝트 수준은 세 곳 모두 무료로 충분해요.
- **수정하면 다시 올려야 하나요?** B, C는 GitHub에 저장(push)하면 자동으로 바뀌어요. A는 다시 끌어다 놓아요.
- **내 주소(도메인)를 갖고 싶어요.** 도메인을 산 뒤 각 서비스의 Domains 설정에서 연결할 수 있어요. AI에게 물어보세요.
