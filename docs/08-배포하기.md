# 8. 인터넷에 올리기 (배포)

내가 만든 걸 친구에게 **링크로** 보여주는 방법이에요. 가장 쉬운 건 그냥 `/deploy` 라고 입력하는 거예요. AI가 내 프로젝트에 맞는 방법을 골라 단계별로 안내해 줘요.

> 💡 **일찍, 자주 올려보세요.** 완벽해질 때까지 기다리지 말고 첫 화면이 나오면 바로 올려보는 게 좋아요. 휴대폰에서 열어보면 내 컴퓨터에선 몰랐던 문제가 보여요.

## 올리기 전에 꼭

1. `/review` — 비밀 키가 코드에 들어가 있지 않은지 확인
2. `/save` — 저장

## 방법 3가지

### A. Netlify Drop — GitHub 몰라도 됨 (HTML 프로젝트)

1. [app.netlify.com/drop](https://app.netlify.com/drop) 접속
2. 프로젝트 폴더를 브라우저 창에 **끌어다 놓기**
3. 주소가 바로 나옴 (계속 유지하려면 무료 가입)

### B. GitHub Pages — 무료, 저장하면 자동 반영 (HTML 프로젝트)

1. 프로젝트를 GitHub에 올리기 (AI에게 "GitHub에 올리는 거 도와줘")
2. GitHub 레포 → **Settings** → 왼쪽 **Pages**
3. Branch를 `main`, 폴더를 `/ (root)`로 → **Save**
4. 1~2분 뒤 `https://내아이디.github.io/레포이름/` 으로 접속

### C. Vercel — React, Next.js 같은 프로젝트

1. [vercel.com](https://vercel.com) 에 GitHub로 가입
2. **Add New → Project** → 내 레포 선택 → **Deploy**
3. 비밀 키가 필요하면 **Settings → Environment Variables** 에 넣기 (`.env` 파일은 올리지 않아요)

## 자주 묻는 것

- **돈 드나요?** 개인 프로젝트 수준은 세 곳 모두 무료로 충분해요.
- **수정하면 다시 올려야 하나요?** B, C는 GitHub에 저장(push)하면 자동으로 바뀌어요. A는 다시 끌어다 놓아요.
- **내 주소(도메인)를 갖고 싶어요.** 도메인을 산 뒤 각 서비스의 Domains 설정에서 연결할 수 있어요. AI에게 물어보세요.
