# 6. 첫 프로젝트 아이디어

뭘 만들지 모르겠다면 하나 골라서 `/start` 할 때 말해보세요. ⭐ 개수 = 난이도

## ⭐ 30분이면 첫 결과가 보이는 것

- **나만의 자기소개 페이지** — 사진, 소개글, SNS 링크
- **오늘 뭐 먹지 룰렛** — 버튼 누르면 메뉴가 랜덤으로
- **D-day 카운터** — 시험·여행까지 며칠 남았는지
- **물 마시기 카운터** — 버튼으로 세고, 새로고침해도 유지

## ⭐⭐ 하루 정도

- **할 일 목록 (To-do)** — 추가, 완료 체크, 삭제
- **단어 암기 카드** — 뒤집기, 맞힌 것/틀린 것 분류
- **뽀모도로 타이머** — 25분 집중 / 5분 휴식, 알림 소리
- **가계부 미니** — 지출 입력하고 이번 달 합계 보기

## ⭐⭐⭐ 며칠 걸리지만 뿌듯한 것

- **간단한 게임** — 두더지 잡기, 숫자 맞히기, 반응속도 테스트
- **날씨 보여주는 페이지** — 공공 API 사용해보기
- **친구들과 같이 쓰는 투표 페이지** — 데이터베이스(Supabase 등) 맛보기
- **나만의 업무 자동화** — 엑셀 정리, 파일 이름 일괄 변경 (Python)
