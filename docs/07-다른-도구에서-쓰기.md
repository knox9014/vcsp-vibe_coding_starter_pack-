# 7. 다른 AI 도구에서 쓰기

이 스타터 팩은 Claude Code 기준으로 만들었지만, **핵심 지침을 `AGENTS.md` 한 곳에 모아뒀기 때문에** 다른 AI 코딩 도구에서도 같은 "초보자 코칭 모드"로 동작해요.

## 도구별로 읽는 파일

| 도구 | 자동으로 읽는 파일 | 슬래시 명령어 |
|---|---|---|
| **Claude Code** | `CLAUDE.md` → `AGENTS.md` | ✅ `/start` 등 그대로 사용 |
| **Cursor** | `AGENTS.md`, `.cursor/rules/00-vcsp.mdc` | 채팅에 "시작", "다음", "저장"이라고 말하기 |
| **OpenAI Codex** | `AGENTS.md` | 말로 요청 |
| **Gemini CLI** | `GEMINI.md` → `AGENTS.md` | 말로 요청 |
| **GitHub Copilot** | `.github/copilot-instructions.md` | 말로 요청 |

Claude Code 외의 도구에서는 `/start` 대신 **"시작하고 싶어"**, `/save` 대신 **"저장해줘"**처럼 말하면 돼요. AI가 `AGENTS.md`의 명령어 표를 보고 해당 절차 파일을 읽어서 똑같이 진행해요.

> 안전장치(위험 명령 차단 훅, 권한 설정)는 Claude Code 전용이에요. 다른 도구에서는 각 도구의 설정에서 "명령 실행 전 확인" 옵션을 켜 두세요.

## 그럼 어떤 도구를 써야 하나요?

처음이라면 **하나만 골라서 익숙해지는 게** 제일 중요해요.

| 종류 | 예시 | 장점 | 단점 |
|---|---|---|---|
| **AI 코딩 에이전트** (이 스타터 팩 대상) | Claude Code, Cursor, Codex, Gemini CLI | 내 컴퓨터에 진짜 파일이 생김. 뭐든 만들 수 있음 | 처음 설치가 조금 필요 |
| **브라우저 앱 빌더** | Lovable, Bolt, v0, Replit | 설치 없이 바로 시작. 배포 버튼까지 있음 | 복잡해지면 한계, 다른 곳으로 옮기기 어려울 수 있음 |

추천 흐름:
1. 아이디어가 맞는지 빨리 보고 싶다 → 브라우저 앱 빌더로 10분 맛보기
2. 제대로 내 것으로 만들고 싶다 → 이 스타터 팩 + AI 코딩 에이전트
