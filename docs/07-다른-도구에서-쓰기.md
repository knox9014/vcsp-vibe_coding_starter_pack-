# 7. 어떤 AI에서든 쓰기

이 스타터 팩은 특정 AI 전용이 아니라 **지침서**예요. 핵심 규칙(초보자 코칭 모드)은 똑같고, AI 종류에 따라 시작하는 방법만 달라요. Windows와 Mac 모두 같아요.

## 1. 채팅 AI (ChatGPT · Claude · Gemini 웹사이트/앱)

설치가 필요 없어요. 대신 AI가 내 컴퓨터 파일을 직접 만들 수 없어서, **AI가 준 코드를 내가 파일로 저장**해요.

1. [`채팅AI용-지침.md`](../채팅AI용-지침.md)의 회색 상자를 복사해 새 대화에 붙여넣기
2. `시작` 입력
3. AI가 주는 파일을 `my-project` 폴더에 저장하고 더블클릭으로 열어보기

- 💡 ChatGPT·Claude의 **프로젝트**, Gemini의 **Gem**을 쓰면 지침을 한 번만 넣어두면 돼요.
- 저장·되돌리기는 **폴더 복사**로 해요 (자세한 건 그 파일에 있어요).
- 대화가 길어지면 "마무리"라고 해서 `PROJECT.md`를 받아 저장하고, 새 대화에 붙여넣어 이어가세요.

## 2. AI 코딩 도구 (파일을 직접 만들어 주는 AI)

이 폴더를 열기만 하면 각 도구가 지침 파일을 자동으로 읽어요.

| 도구 | 자동으로 읽는 파일 | 명령어 |
|---|---|---|
| **Claude Code** | `CLAUDE.md` → `AGENTS.md` | ✅ `/start` 등 그대로 사용 + 자동 안전장치 |
| **Cursor** | `AGENTS.md`, `.cursor/rules/00-vcsp.mdc` | "시작", "다음", "저장"이라고 말하기 |
| **OpenAI Codex** | `AGENTS.md` | 말로 요청 |
| **Gemini CLI** | `GEMINI.md` → `AGENTS.md` | 말로 요청 |
| **GitHub Copilot** | `.github/copilot-instructions.md` | 말로 요청 |

Claude Code 외의 도구에서는 `/start` 대신 **"시작하고 싶어"**, `/save` 대신 **"저장해줘"**처럼 말하면 돼요. AI가 `AGENTS.md`의 명령어 표를 보고 해당 절차 파일을 읽어서 똑같이 진행해요.

> ⚠️ 자동 안전장치(위험 명령 차단, `.env` 보호, 권한 설정)는 **Claude Code 전용**이에요. 다른 도구에서는 AI가 지침으로만 따르니, 각 도구 설정에서 **"명령 실행 전 확인"** 옵션을 꼭 켜 두세요.

## 그럼 뭘 쓰면 좋을까요?

처음이라면 **하나만 골라서 익숙해지는 게** 제일 중요해요.

| 종류 | 예시 | 장점 | 단점 |
|---|---|---|---|
| **채팅 AI** | ChatGPT, Claude, Gemini | 설치 없음. 이미 쓰고 있을 수도 | 파일을 직접 저장해야 함. 커지면 번거로움 |
| **AI 코딩 도구** | Claude Code, Cursor, Codex, Gemini CLI | 파일을 직접 만들고, 저장·되돌리기가 자동 | 처음 설치가 조금 필요 |
| **브라우저 앱 빌더** | Lovable, Bolt, v0, Replit | 설치 없이 바로. 배포 버튼까지 있음 | 이 지침서와는 따로 동작. 옮기기 어려울 수 있음 |

추천 흐름:
1. 일단 맛보기 → **채팅 AI** + `채팅AI용-지침.md`
2. 재밌어서 제대로 해보고 싶다 → **Claude Code** (또는 다른 AI 코딩 도구) + 이 폴더
