# 4. 막혔을 때

일단 심호흡 🫁 그리고 `/fix` 를 입력하세요. 아래는 자주 겪는 상황들이에요.

## 화면이 하얗게만 나와요

- 브라우저에서 **F12** (Mac: `Cmd + Option + I`) → **Console** 탭의 빨간 글씨를 복사해서 AI에게 붙여넣으세요.

## 고쳤다는데 화면이 그대로예요

- 브라우저 **새로고침** 했나요? 안 되면 강력 새로고침: `Ctrl + Shift + R` (Mac: `Cmd + Shift + R`)
- 다른 파일을 열어보고 있는 건 아닌지 확인하세요.

## AI가 같은 실수를 반복해요

- "지금까지 시도한 방법은 안 됐어. 완전히 다른 방법으로 해줘"라고 말하세요.
- 그래도 안 되면 `/undo`로 잘 되던 지점으로 돌아가서, 기능을 더 작게 쪼개 다시 요청하세요.

## AI가 아까 한 말을 까먹은 것 같아요 / 대화가 너무 길어요

- 대화가 길어지면 AI의 기억이 흐려져요. `/wrap`으로 진행 상황을 `my-project/PROJECT.md`에 정리한 뒤, **새 대화**(Claude Code에선 `/clear`)를 열고 `/next`라고 하세요. 훨씬 똑똑해져요.

## "🛑 안전장치가 이 명령을 막았어요"라고 나와요

- 되돌릴 수 없는 명령(컴퓨터 전체 삭제, 강제 푸시, 비밀 키 출력 등)이라 막은 거예요. AI가 다른 방법을 찾을 거예요. 궁금하면 "왜 그 명령이 필요했어?"라고 물어보세요.

## "⚠️ … 허용할까요?" 확인 창이 떠요

- 폴더 삭제처럼 **조심해야 하지만 가끔 필요한** 명령이에요. 창에 적힌 이유를 읽고, AI가 지우려는 게 뭔지 이해되면 허용하세요.
- 잘 모르겠으면 거절하고 "방금 그거 뭐 하려던 거야?"라고 물어보세요. 거절해도 아무 일도 안 생겨요.

## 다 망가졌어요

- `/undo` → 마지막 저장 지점으로 돌아갈 수 있어요. 그래서 `/save`를 자주 하는 게 중요해요.

## `command not found` / `'xxx'은(는) 내부 또는 외부 명령...이 아닙니다`

- 그 프로그램이 설치 안 된 거예요. AI에게 "○○ 설치하는 법 알려줘. 내 컴퓨터는 Mac(또는 Windows)이야"라고 물어보세요.

## `npm install` 하라는데 무서워요

- 남이 만든 코드 묶음(라이브러리)을 내 프로젝트에 가져오는 거예요. 이 스타터 팩은 설치 전에 항상 허락을 묻게 돼 있어요. 무엇을 왜 설치하는지 물어보고 결정하세요.

## AI가 허락을 너무 자주 물어봐요

- 파일 수정은 묻지 않도록 이미 설정돼 있어요. 프로그램 설치(`npm install`)나 GitHub에 올리기(push)는 안전을 위해 일부러 물어보게 해뒀어요.
- 익숙해지면 AI에게 "npm install은 안 물어보게 설정해줘"라고 하면 내 컴퓨터 설정(`.claude/settings.local.json`)에만 추가해 줘요.

## API 키를 실수로 GitHub에 올렸어요 😱

1. **바로 그 서비스 사이트에 가서 키를 삭제(폐기)하고 새로 발급**받으세요. 파일에서 지우는 것만으론 부족해요 (기록에 남아요).
2. 새 키는 `.env` 파일에만 넣으세요.
