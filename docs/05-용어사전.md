# 5. 용어 사전

모르는 단어가 나오면 여기서 찾거나, 그냥 AI에게 `/explain 단어` 하세요.

| 용어 | 쉬운 설명 |
|---|---|
| **프롬프트** | AI에게 하는 말·요청 |
| **HTML** | 웹페이지의 뼈대 (제목, 버튼, 글자가 *무엇*인지) |
| **CSS** | 웹페이지의 옷 (색, 크기, 위치 등 *어떻게 보일지*) |
| **JavaScript (JS)** | 웹페이지의 움직임 (버튼 누르면 *무슨 일이 일어날지*) |
| **브라우저** | 크롬, 사파리, 엣지 같은 인터넷 보는 프로그램 |
| **터미널** | 글자로 컴퓨터에 명령하는 검은 창 |
| **폴더 / 디렉터리** | 같은 말. 파일 담는 곳 |
| **Git** | 파일 변경 기록을 남겨주는 도구. 게임 세이브 기능 같은 것 |
| **커밋 (commit)** | 세이브 포인트 하나. `/save`가 해주는 것 |
| **GitHub** | Git 기록을 인터넷에 올려두는 곳. 백업 + 공유 |
| **푸시 (push)** | 내 컴퓨터의 기록을 GitHub에 올리기 |
| **레포 (repository)** | 프로젝트 하나의 폴더 + 기록 전체 |
| **라이브러리 / 패키지** | 남이 만들어둔 코드 묶음. 가져다 쓰면 편함 |
| **npm** | JavaScript 라이브러리를 설치해주는 도구 |
| **API** | 다른 서비스에 기능을 요청하는 창구 (예: 날씨 정보 받아오기) |
| **API 키** | API를 쓸 수 있는 비밀 열쇠. **절대 공개 금지** |
| **.env** | 비밀 열쇠들을 넣어두는 파일. GitHub에 안 올라감 |
| **배포 (deploy)** | 내가 만든 걸 인터넷에 올려서 남들도 볼 수 있게 하는 것 |
| **로컬 (localhost)** | 내 컴퓨터 안에서만 돌아가는 상태 |
| **에러 / 버그** | 뭔가 잘못된 것. 누구나 매일 만납니다 |
| **콘솔** | 브라우저가 에러를 알려주는 곳 (F12 → Console) |
| **프론트엔드** | 사용자 눈에 보이는 화면 쪽 |
| **백엔드** | 화면 뒤에서 데이터를 저장·처리하는 쪽 |
| **데이터베이스 (DB)** | 데이터를 저장하는 창고 |
| **localStorage** | 브라우저 안에 작은 데이터를 저장하는 곳. 새로고침해도 남음 |
| **React / Vue** | 복잡한 화면을 만들기 쉽게 해주는 도구. 처음엔 몰라도 OK |
