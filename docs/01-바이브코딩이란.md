# 1. 바이브 코딩이란?

## 한 줄 정의

**내가 원하는 걸 말로 설명하면 AI가 코드를 쓰고, 나는 결과를 보면서 "이건 좋고, 이건 이렇게 바꿔줘"라고 방향을 잡는 방식**이에요.

## 내 역할 vs AI 역할

| 나 (감독) | AI (실무자) |
|---|---|
| 뭘 만들지 정한다 | 코드를 쓴다 |
| 결과를 직접 눈으로 확인한다 | 에러를 찾고 고친다 |
| 마음에 안 들면 구체적으로 말한다 | 낯선 개념을 설명해 준다 |
| 잘 되면 저장(`/save`)한다 | 다음 단계를 제안한다 |

코드를 몰라도 됩니다. 대신 **"확인하는 눈"**이 중요해요. AI가 "다 했어요!"라고 해도, 직접 열어보고 눌러보세요.

## 마음가짐 5가지

1. **작게 시작하세요.** "인스타그램 같은 앱"보다 "사진 한 장 올리면 보여주는 페이지"부터.
2. **한 번에 하나씩.** 여러 기능을 한꺼번에 요청하면 꼬이기 쉬워요.
3. **자주 저장하세요.** 잘 될 때마다 `/save`. 망하면 `/undo`. 이것만 알면 무서울 게 없어요.
4. **모르면 물어보세요.** `/explain` 은 아무리 많이 써도 됩니다. 바보 같은 질문은 없어요.
5. **AI도 틀립니다.** 두세 번 시도해도 안 되면 방향을 바꾸거나 더 단순하게 가세요.

## 하루 흐름 예시

```
/start          → 아이디어 정리, 첫 화면 만들기
(화면 확인)
"버튼 색을 파란색으로 바꿔줘"
(확인) 👍
/save           → 저장
/next           → 다음 기능
(뭔가 깨짐) 😱
/fix            → 고치기
/save
```
