# 3. AI에게 말 잘 거는 법

## 핵심 공식

> **무엇을** + **어디에** + **어떻게 보이면 성공인지**

| ❌ 애매함 | ✅ 구체적 |
|---|---|
| 예쁘게 해줘 | 배경은 연한 베이지, 글씨는 둥근 느낌으로, 카드마다 그림자 살짝 넣어줘 |
| 버튼 고쳐줘 | "추가" 버튼을 눌러도 목록에 아무것도 안 생겨. 눌렀을 때 입력한 글이 아래 목록에 추가되게 해줘 |
| 로그인 만들어줘 | 일단 진짜 로그인 말고, 이름만 입력하면 "○○님 안녕하세요"가 뜨게 해줘 |
| 앱 만들어줘 | 오늘 마신 물 잔 수를 버튼으로 세고, 새로고침해도 숫자가 유지되는 페이지 만들어줘 |

## 상황별 말하기 예시

**처음 만들 때**
> 단어 카드 앱을 만들고 싶어. 앞면에 영어, 누르면 뒤집혀서 한국어가 보이게. 일단 카드 3장만 하드코딩해서 보여줘.

**모양 바꿀 때**
> 지금 카드가 너무 작아. 휴대폰 화면 너비의 80% 정도로 키워줘.

**참고 이미지가 있을 때**
> (스크린샷 붙여넣기) 이 느낌으로 상단 메뉴를 바꿔줘.

**에러가 났을 때**
> 버튼 누르면 아무 일도 안 일어나. 콘솔에 이런 에러가 떠: (에러 복사해서 붙여넣기)

**이해가 안 될 때**
> 방금 만든 `script.js`에서 `addEventListener`가 뭐야? 쉽게 설명해줘.

**AI가 너무 많이 바꿨을 때**
> 잠깐, 나는 색만 바꾸고 싶었어. 다른 건 건드리지 말고 색만 바꿔줘.

## 꿀팁

- **스크린샷은 천 마디 말보다 낫다.** 화면이 이상하면 캡처해서 붙여넣으세요.
- **"왜?"를 물어보세요.** "왜 이렇게 했어?"라고 물으면 더 나은 방법이 나오기도 해요.
- **대화가 너무 길어지면 새로 시작하세요.** `my-project/PROJECT.md`에 진행 상황이 있으니 `/next` 하나면 이어서 할 수 있어요.
- **계획 먼저 받기:** 큰 작업이면 "코드 쓰기 전에 어떻게 할지 계획부터 말해줘"라고 하세요.
